# creator.dm 操作マニュアル（DM送付担当者向け）

毎日やることは **2つだけ** です。所要時間は1日あたり2〜3分です。

1. **今日の入力** … その日の送付数と返信数を入れる
2. **返信者管理** … 返信があったクリエイターを登録する

---

## 1. ログイン

1. ブラウザで **https://creator-dm.vercel.app** を開く
2. 管理者から渡された **ログインID** と **パスワード** を入力
3. 「ログイン」を押す

> スマホでも使えます。ブラウザのメニューから「ホーム画面に追加」しておくと、
> アプリのように1タップで開けて便利です。

ログインすると、上部に4つのタブが並んだ画面が開きます。

| タブ | 何をするところ |
| --- | --- |
| **今日の入力** | 毎日の送付数・返信数を入れる（メイン） |
| **自分の実績** | 自分の送付数・返信率・報酬の見込みを見る |
| **返信者管理** | 返信があったクリエイターを登録する |
| **送付文章** | 自分のDM文面を確認・コピー・編集する |

---

## 2. 毎日の入力（今日の入力タブ）

自分のアカウントが縦に並んでいます。アカウントごとに、その日の実績を入れます。

1. **送付数** に、その日そのアカウントから送ったDMの件数を入れる
2. **返信数** に、そのうち返信がきた件数を入れる
3. 必要ならメモ欄に状況を書く（例：「制限がかかった」）
4. 一番下の **「この日の実績を保存」** を押す

入力している間、画面下のバーに **合計と目標、返信率** がリアルタイムで出ます。
保存すると画面上部に「保存しました」と表示されます。

### 覚えておくこと

- **送っていない日も「0」で保存してください。** 未入力のままだと「入力忘れ」として
  管理者にアラートが出ます。
- **返信数が送付数を超えていると保存ボタンが押せません。** 数字を確認してください。
- **停止中・BANのアカウントは表示されません。** 表示がおかしいときは管理者に連絡してください。

### 入力を忘れた日を後から入れる

画面下の **「直近7日の入力状況」** に、7日分が並んでいます。

- **赤い「未入力」** … まだ入れていない日
- **緑の数字** … 入力済みの日

赤いところをタップすると、その日の入力画面に切り替わります。そのまま入力して保存してください。
すでに入力した日を押せば、上書きして修正できます。

---

## 3. 返信があったら（返信者管理タブ）

DMに返信をくれたクリエイターを登録します。入力するのは **4項目だけ** です。

| 項目 | 入れるもの |
| --- | --- |
| クリエイターID | 相手のTikTokのID（@は不要） |
| 送付アカウント | どのアカウントから送ったか |
| 返信日 | 返信がきた日（初期値は今日） |
| LINE誘導日 | LINE登録してもらえた日。**まだなら空欄でOK** |

「登録する」を押せば完了です。

### あとからLINEに誘導できたとき

一覧の **「LINE誘導済みにする」** ボタンを押すだけで、今日の日付が入ります。
別の日付にしたい場合は「編集」から日付を指定してください。

> **面談の記録は管理者が行います。** 面談欄は表示されるだけで、こちらでは入力しません。

---

## 4. DMの文面を確認する（送付文章タブ）

自分の文面が2種類に分かれて表示されます。

- **送付文（初回DM）** … クリエイターに最初に送る文面
- **返信文（返信後のトーク）** … 返信をもらったあとにLINEへ誘導する文面

**「本文をコピー」** を押すとコピーされるので、そのままTikTokに貼り付けられます。

### 文面を変えたいとき

「この文章を編集する」を開いて、本文を直して「保存する」を押します。

- 保存するたびに **新しい版として記録** されます
- 「変更履歴」から **いつでも前の文面に戻せます**
- 何を変えたかメモを残しておくと、後で振り返りやすくなります

---

## 5. 自分の実績を見る（自分の実績タブ）

- 今月の送付数・返信数・返信率
- 直近30日の推移グラフ
- アカウントごとの返信率
- 今月の報酬の見込み（確定前の概算です）

**特定のアカウントだけ返信率が極端に低い場合**は、そのアカウントに制限がかかっている
可能性があります。管理者に相談してください。

---

## 困ったときは

| こんなとき | どうする |
| --- | --- |
| パスワードを忘れた | 管理者に連絡して再設定してもらう |
| アカウントが表示されない | 管理者に登録・状態の確認を依頼する |
| 間違えて保存した | 同じ日をもう一度開いて、正しい数字で保存し直す（上書きされます） |
| 面談の日程が決まった | 管理者に伝える（この画面では入力しません） |
| 画面が真っ白・エラーが出る | 一度ページを再読み込みする。直らなければ管理者に連絡 |

---

*不明点は管理者までご連絡ください。*
